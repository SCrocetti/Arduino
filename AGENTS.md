# Arduino Projects Repository

## Structure
- Each project lives in `projects/<NN>-project_name/`
- Standard subfolders: `code/`, `circuit/`, `asets/` (note: typo preserved)
- Code files are Arduino sketches (`.ino`)

## Working with Arduino
- Open `.ino` files in Arduino IDE
- Test by uploading to physical hardware
- Schematics in `circuit/*.kicad_sch`
