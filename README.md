---

### 🔹 03 - LED Matrix

---

### 🔹 04 - LED Switching Experiments

Exploring timing and LED control techniques.

---

### 🔹 05 - LED Matrix Sweep

Animated sweeping patterns across a matrix.

---

### 🔹 06 - Shift Register

---

### 🔹 07 - LED Matrix + Shift Register

Combining matrix control with shift registers.
