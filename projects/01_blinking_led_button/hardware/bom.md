## 🇺🇸 English
<a id="english"></a>

### 🛠️ Core Components
| Ref | Component | Value | Package | Description |
| :--- | :--- | :--- | :--- | :--- |
| **U1** | Arduino Uno | R3 | Board | Main Microcontroller |
| **D1** | LED | Red | 5mm THT | Status Indicator |
| **R1** | Resistor | 220Ω | Axial | LED Current Limiter |
| **R2** | Resistor | 10kΩ | Axial | Button Pull-down |
| **S1** | Push Button | 6x6mm | 4-pin THT | Tactile Switch |

### 🔌 Connection & Prototyping
* **Breadboard**: 1x Half-size (400 points).
* **Jumper Wires**: 10x Male-to-Male (M-M).
* **USB Cable**: 1x Type-A to Type-B for power and data.
